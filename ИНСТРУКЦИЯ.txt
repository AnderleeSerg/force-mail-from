ENGLISH — 4 steps
-----------------
1. Create a mailbox on the site domain, e.g. admin@mysite.com
   (Mail → Mailboxes in adm.tools)

2. My sites → your site → Settings → Outgoing mail
   → choose that mailbox → Save
   Without this step the file will not help.

3. Put force-mail-from.php here:
     wp-content/mu-plugins/force-mail-from.php
   Create the mu-plugins folder if it is missing.
   You do not activate it under WordPress “Plugins”.

4. Open the file only if the mailbox is NOT admin@
   Find:  define( 'FORCE_MAIL_USER', 'admin' );
   For info@mysite.com change admin to info.


УКРАЇНСЬКА — 4 кроки
--------------------
1. Створіть скриньку на домені сайта, напр. admin@mysite.com
   (Пошта → Поштові скриньки в adm.tools)

2. Мої сайти → ваш сайт → Налаштування → Вихідна пошта
   → оберіть цю скриньку → Зберегти
   Без цього кроку файл не допоможе.

3. Покладіть force-mail-from.php сюди:
     wp-content/mu-plugins/force-mail-from.php
   Теку mu-plugins створіть, якщо її немає.
   У WordPress у «Плагіни» активувати не треба.

4. Відкрийте файл, лише якщо скринька НЕ admin@
   Знайдіть:  define( 'FORCE_MAIL_USER', 'admin' );
   Для info@mysite.com замініть admin на info.


РУССКИЙ — 4 шага
----------------
1. Создайте ящик на домене сайта, напр. admin@mysite.com
   (Почта → Почтовые ящики в adm.tools)

2. Мои сайты → ваш сайт → Настройки → Исходящая почта
   → выберите этот ящик → Сохранить
   Без этого шага файл не поможет.

3. Положите force-mail-from.php сюда:
     wp-content/mu-plugins/force-mail-from.php
   Папку mu-plugins создайте, если её нет.
   В WordPress в «Плагины» активировать не нужно.

4. Откройте файл, только если ящик НЕ admin@
   Найдите:  define( 'FORCE_MAIL_USER', 'admin' );
   Для info@mysite.com замените admin на info.
