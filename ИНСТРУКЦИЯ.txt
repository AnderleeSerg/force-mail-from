Force Mail From — for site administrators
=========================================
https://github.com/AnderleeSerg/force-mail-from

The host blocked mail from the site (Invalid From).
This file is for WordPress on Hosting Ukraine (adm.tools).
You do not need to be a programmer.


ENGLISH
-------
1. Mail → Mailboxes → create admin@mysite.com

2. My sites → your site → Settings → Outgoing mail
   → choose that mailbox → Save

3. File manager → site folder → www → wp-content
   Create folder mu-plugins if it is missing.
   Upload force-mail-from.php into mu-plugins.

   Do not look for it under Plugins in WordPress. It turns on by itself.

4. Open the file in Notepad only if the mailbox is NOT admin@
   Change the word admin to info if the mailbox is info@...


УКРАЇНСЬКА
----------
1. Пошта → Поштові скриньки → створіть admin@mysite.com

2. Мої сайти → ваш сайт → Налаштування → Вихідна пошта
   → оберіть цю скриньку → Зберегти

3. Файл-менеджер → тека сайта → www → wp-content
   Створіть теку mu-plugins, якщо її немає.
   Завантажте force-mail-from.php у mu-plugins.

   У WordPress у «Плагіни» файл шукати не треба. Він вмикається сам.

4. Відкрийте файл у блокноті, лише якщо скринька НЕ admin@
   Замініть слово admin на info, якщо скринька info@...


РУССКИЙ
-------
1. Почта → Почтовые ящики → создайте admin@mysite.com

2. Мои сайты → ваш сайт → Настройки → Исходящая почта
   → выберите этот ящик → Сохранить

3. Файл-менеджер → папка сайта → www → wp-content
   Создайте папку mu-plugins, если её нет.
   Загрузите force-mail-from.php в mu-plugins.

   В WordPress в «Плагины» файл искать не нужно. Он включается сам.

4. Откройте файл в блокноте, только если ящик НЕ admin@
   Замените слово admin на info, если ящик info@...
