## Що це

Hosting Ukraine іноді надсилає лист, що лист із сайта **заблоковано**: «Некоректний заголовок From» / Invalid From.

Так буває, коли WordPress надсилає пошту від Gmail (або іншої чужої адреси). Хостинг пропускає лише скриньку, яка є **на вашому хостингу**, на **тому ж домені, що й сайт**.

Цей файл змушує WordPress надсилати саме від такої скриньки. Плагін безкоштовний.

Документація хостингу: https://www.ukraine.com.ua/wiki/mail/issues/invalid-from/

## Що зробити (4 кроки)

### 1. Створіть поштову скриньку

У панелі хостингу ([adm.tools](https://adm.tools/)): **Пошта → Поштові скриньки → створити**.

Приклад: сайт `mysite.com` — скринька `admin@mysite.com`.  
Пароль запишіть. Щодня цю скриньку читати не обов’язково — вона потрібна, щоб хостинг **дозволив відправлення**.

### 2. Увімкніть відправлення для сайта

**Хостинг → Мої сайти → ваш сайт → Налаштування.**

Знайдіть **Вихідна пошта**, оберіть скриньку з кроку 1, натисніть **Зберегти**.

Без цього кроку файл не допоможе.

### 3. Покладіть файл на сайт

Завантажте [`force-mail-from.php`](force-mail-from.php) (або **Code → Download ZIP**).

На сервері, у файлах сайта, відкрийте теку `wp-content`.  
Якщо немає теки `mu-plugins` — створіть.  
Покладіть файл сюди:

```text
wp-content/mu-plugins/force-mail-from.php
```

У WordPress у розділі «Плагіни» його шукати не треба. Такий файл вмикається сам.

Якщо WordPress-сайтів кілька — скопіюйте **той самий** файл на кожен.

### 4. Лише якщо скринька не admin@

Відкрийте файл у блокноті. Знайдіть рядок:

```php
define( 'FORCE_MAIL_USER', 'admin' );
```

Якщо скринька `info@mysite.com` — замініть `admin` на `info`.  
Якщо `admin@mysite.com` — нічого не змінюйте.

## Як зрозуміти, що спрацювало

Надішліть будь-який тест із сайта (форма, «забули пароль»).  
Відправник має бути `admin@ваш-домен`, не Gmail.  
Наступного дня хостинг не має надіслати лист про поганий From.
