# Force Mail From

**Плагін WordPress, який зупиняє листи хостингу про помилку «Некоректний заголовок From» (Invalid From).**

Якщо ви на [Hosting Ukraine](https://www.ukraine.com.ua/) (панель [adm.tools](https://adm.tools/)) і вам постійно приходять повідомлення, що вихідний лист із сайту **заблоковано** через неправильний `From` — цей файл саме про це.

Типовий текст від хостингу:

> Вихідний лист заблоковано  
> Некоректний заголовок From  
> Invalid From header

WordPress, WooCommerce, Contact Form 7 або плагін безпеки часто надсилають лист від `ви@gmail.com` або від неіснуючої `wordpress@сайт.com`. Хостинг таке не пропускає: відправник має бути **скринькою, яку справді створено на тому ж акаунті**.

Плагін змушує WordPress завжди надсилати від скриньки домену сайта. Якщо у формі був Gmail відвідувача, він потрапляє в **Reply-To** — йому й надалі можна відповісти.

Документація хостингу: [Некоректний заголовок From](https://www.ukraine.com.ua/wiki/mail/issues/invalid-from/)

## Завантажити

- Файл плагіна: [`force-mail-from.php`](force-mail-from.php)
- Або архів: зелена кнопка **Code → Download ZIP**

## Кому підходить

- WordPress на Hosting Ukraine та схожих хостингах із тим самим правилом `From`
- Кілька сайтів на одному акаунті — той самий файл на кожен WordPress

**Не потрібен**, якщо пошта вже йде через зовнішній SMTP (WP Mail SMTP + Gmail, SendPulse тощо).  
**Не допоможе** OpenCart і самописному PHP — лише WordPress.

## Встановлення

1. Створіть на хостингу поштову скриньку на домені сайта, наприклад `admin@ваш-сайт.com`.
2. **Мої сайти → сайт → Налаштування → «Вихідна пошта»** — оберіть цю скриньку і збережіть.
3. Скопіюйте `force-mail-from.php` у теку:

   ```text
   wp-content/mu-plugins/force-mail-from.php
   ```

   Теки `mu-plugins` може не бути — створіть її.  
   У розділі «Плагіни» нічого активувати не потрібно: mu-plugins підхоплюються самі.

4. Якщо скринька не `admin@домен`, змініть у файлі один рядок:

   ```php
   define( 'FORCE_MAIL_USER', 'admin' );
   ```

   `info` → листи від `info@ваш-сайт.com`. Домен підставиться сам.

## Кілька сайтів і винятки

Файл один на всі сайти: `admin` на `a.com` дасть `admin@a.com`, на `b.com` — `admin@b.com`.

Якщо скринька називається інакше (`info@`, `sales@`) або в сайта немає власної скриньки — заповніть карту у файлі:

```php
$GLOBALS['FORCE_MAIL_MAP'] = array(
    'shop.com' => 'sales@shop.com',
    'old.com'  => 'admin@main.com',
);
```

Скринька в панелі та адреса у файлі мають збігатися. Інакше хостинг знову заблокує лист.

## Як перевірити

1. Надішліть тестовий лист (форма, «забули пароль», звіт безпеки).
2. Відправник у листі — `ви@домен-сайта`, не Gmail.
3. Наступного дня не має прийти повідомлення хостингу про некоректний `From`.
