# Force Mail From

**[English](README.md)** · **[Українська](README.uk.md)** · **[Русский](README.ru.md)**

[![Підтримати / Donate](https://img.shields.io/badge/Підтримати%20%2F%20Donate-Monobank-e11d48)](https://send.monobank.ua/jar/2Y8epr7u5T)

Хостинг надіслав лист, що лист із сайта **заблоковано** («Некоректний заголовок From» / Invalid From).  
Цей безкоштовний файл це виправляє для WordPress на [Hosting Ukraine](https://www.ukraine.com.ua/) ([adm.tools](https://adm.tools/)).

Програмістом бути не треба. Зробіть три кроки нижче.

## 1. Створіть скриньку (якщо її ще немає)

У **adm.tools**: **Пошта → Поштові скриньки → Створити**.

Назвіть її як сайт, наприклад `admin@mysite.com`, якщо сайт `mysite.com`.

Пароль збережіть. Щодня цю скриньку читати не обов’язково. Вона потрібна, щоб хостинг **дозволив відправлення**.

## 2. Укажіть сайту надсилати від цієї скриньки

**Хостинг → Мої сайти → ваш сайт → Налаштування.**

Знайдіть **Вихідна пошта**, оберіть `admin@mysite.com`, натисніть **Зберегти**.

Якщо цей крок пропустити, файл не допоможе.

## 3. Завантажте файл

Завантажте [`force-mail-from.php`](force-mail-from.php)  
(або зелена кнопка **Code → Download ZIP**, потім візьміть файл `.php` з архіву).

У **adm.tools** відкрийте **Файл-менеджер**. Зайдіть у теку сайта, далі:

`www` → `wp-content`

Якщо немає теки `mu-plugins` — створіть (**Нова тека**).  
Відкрийте `mu-plugins` і **завантажте** туди `force-mail-from.php`.

Шлях має бути такий:

```text
wp-content/mu-plugins/force-mail-from.php
```

У WordPress у розділі **Плагіни** цей файл шукати не треба. Він вмикається сам.

Сайтів на WordPress кілька? Той **самий** файл завантажте так само на кожен.

## Якщо скринька не admin@

Лише тоді відкрийте файл у блокноті. Знайдіть:

```php
define( 'FORCE_MAIL_USER', 'admin' );
```

Якщо скринька `info@mysite.com` — замініть `admin` на `info`.  
Якщо вже `admin@...` — нічого не змінюйте.

## Якщо сайт не на WordPress — цей файл не завантажуйте

Файл працює лише у **WordPress**. На OpenCart, Joomla, Prestashop чи самописному PHP він нічого не робить.

Для таких сайтів два кроки — у панелі та в CMS має стояти **та сама існуюча скринька**, не Gmail:

1. **adm.tools:** Мої сайти → сайт → Налаштування → **Вихідна пошта** → наприклад `info@mysite.com` → Зберегти.
2. **У CMS** пошта магазину / відправник (From) — **та сама** скринька.

**OpenCart:** Система → Налаштування → вкладка **Основне** (не «Пошта») → поле **E-Mail**.  
Вкладка «Пошта» — лише Mail або SMTP. Gmail залиште в **переадресації** скриньки, не в From.

## Чи спрацювало?

Надішліть тест із сайта (форма або «забули пароль»).  
Відправник має бути скринька сайта, не Gmail.  
Наступного дня хостинг не має надіслати лист про заблокований From.
