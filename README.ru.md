# Force Mail From

Хостинг прислал письмо, что письмо с сайта **заблокировано** («Некорректный заголовок From» / Invalid From).  
Этот бесплатный файл это исправляет для WordPress на [Hosting Ukraine](https://www.ukraine.com.ua/) ([adm.tools](https://adm.tools/)).

Программистом быть не нужно. Сделайте три шага ниже.

## 1. Создайте ящик (если его ещё нет)

В **adm.tools**: **Почта → Почтовые ящики → Создать**.

Назовите его как сайт, например `admin@mysite.com`, если сайт `mysite.com`.

Пароль сохраните. Каждый день этот ящик читать не обязательно. Он нужен, чтобы хостинг **разрешил отправку**.

## 2. Укажите сайту слать с этого ящика

**Хостинг → Мои сайты → ваш сайт → Настройки.**

Найдите **Исходящая почта**, выберите `admin@mysite.com`, нажмите **Сохранить**.

Если этот шаг пропустить, файл не поможет.

## 3. Загрузите файл

Скачайте [`force-mail-from.php`](force-mail-from.php)  
(или зелёная кнопка **Code → Download ZIP**, потом возьмите файл `.php` из архива).

В **adm.tools** откройте **Файл-менеджер**. Зайдите в папку сайта, дальше:

`www` → `wp-content`

Если нет папки `mu-plugins` — создайте (**Новая папка**).  
Откройте `mu-plugins` и **загрузите** туда `force-mail-from.php`.

Путь должен быть такой:

```text
wp-content/mu-plugins/force-mail-from.php
```

В WordPress в разделе **Плагины** этот файл искать не нужно. Он включается сам.

Сайтов на WordPress несколько? Тот **же** файл загрузите так же на каждый.

## Если ящик не admin@

Только тогда откройте файл в блокноте. Найдите:

```php
define( 'FORCE_MAIL_USER', 'admin' );
```

Если ящик `info@mysite.com` — замените `admin` на `info`.  
Если уже `admin@...` — ничего не меняйте.

## Сработало?

Отправьте тест с сайта (форма или «забыли пароль»).  
Отправитель должен быть ящик сайта, не Gmail.  
На следующий день хостинг не должен прислать письмо про заблокированный From.
