## Что это

Hosting Ukraine иногда присылает письмо, что письмо с сайта **заблокировано**: «Некорректный заголовок From» / Invalid From.

Так бывает, когда WordPress отправляет почту от Gmail (или другого чужого адреса). Хостинг пропускает только ящик, который есть **на вашем хостинге**, на **том же домене, что и сайт**.

Этот файл заставляет WordPress слать именно от такого ящика. Плагин бесплатный.

Документация хостинга: https://www.ukraine.com.ua/wiki/mail/issues/invalid-from/

## Что сделать (4 шага)

### 1. Создайте почтовый ящик

В панели хостинга ([adm.tools](https://adm.tools/)): **Почта → Почтовые ящики → создать**.

Пример: сайт `mysite.com` — ящик `admin@mysite.com`.  
Пароль запишите. Каждый день этот ящик читать не обязательно — он нужен, чтобы хостинг **разрешил отправку**.

### 2. Включите отправку для сайта

**Хостинг → Мои сайты → ваш сайт → Настройки.**

Найдите **Исходящая почта**, выберите ящик из шага 1, нажмите **Сохранить**.

Без этого шага файл не поможет.

### 3. Положите файл на сайт

Скачайте [`force-mail-from.php`](force-mail-from.php) (или **Code → Download ZIP**).

На сервере, в файлах сайта, откройте папку `wp-content`.  
Если нет папки `mu-plugins` — создайте.  
Положите файл сюда:

```text
wp-content/mu-plugins/force-mail-from.php
```

В WordPress в разделе «Плагины» его искать не нужно. Такой файл включается сам.

Если сайтов на WordPress несколько — скопируйте **тот же** файл на каждый.

### 4. Только если ящик не admin@

Откройте файл в блокноте. Найдите строку:

```php
define( 'FORCE_MAIL_USER', 'admin' );
```

Если ящик `info@mysite.com` — замените `admin` на `info`.  
Если `admin@mysite.com` — ничего не меняйте.

## Как понять, что сработало

Отправьте любой тест с сайта (форма, «забыли пароль»).  
Отправитель должен быть `admin@ваш-домен`, не Gmail.  
На следующий день хостинг не должен прислать письмо про плохой From.
